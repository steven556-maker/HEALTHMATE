# دراسة جدوى مبسطة — HEALTHMATE

## الفكرة ونموذج القيمة

تطبيق متابعة وتمرين منزلي يعمل على الهاتف، مع معالجة وضعية الجسم محليًا. القيمة المقترحة هي إتاحة تكرار التدريب بين الزيارات، وتوثيق الالتزام والنوم، وتقديم تلميحات عامة قابلة للتفسير. التطبيق لا يشخّص ولا يستبدل الطبيب أو أخصائي العلاج الطبيعي.

## التكلفة

- التطوير الأولي: وقت فريق المنتج والهندسة والتصميم، واختبار قابلية الاستخدام وإتاحة الواجهة. يُحسب داخليًا وفق عدد أيام العمل × تكلفة اليوم [المصدر].
- التشغيل: استضافة ملفات ثابتة ونسخة PWA؛ يمكن بدء التجربة على خطة مجانية، ثم قياس تكلفة النطاق والتوزيع والمراقبة [المصدر]. لا يحتاج مسار التمرين إلى خادم أو إرسال فيديو.
- API المساعد الاختياري: معطل افتراضيًا. عند تفعيله عبر وسيط آمن، التكلفة = عدد الرموز المدخلة والمخرجة × سعر النموذج في تاريخ الإطلاق [المصدر]. ينبغي وضع حد استخدام وقياس فعلي قبل تسعير الاشتراك.
- الصيانة: تحديث توافق المتصفحات، مراجعة أمنية، اختبار إتاحة، ومراجعة مختصين لحدود الزوايا والتنبيهات [المصدر].

## نموذج الاستفادة المقترح

نسخة مجانية للأفراد تشمل التدريب المحلي والسجل. اشتراك للمراكز والجيم ودور المسنين يوفر إدارة مستخدمين بموافقتهم، تقارير مجمعة، وتدريبًا للعاملين؛ التسعير يُختبر بمقابلات وتجربة مدفوعة صغيرة قبل تثبيته [المصدر]. لا تبيع بيانات صحية ولا تفعّل المساعد دون موافقة واضحة.

## مقارنة البدائل

الجلسة الشخصية تقدم تقييمًا بشريًا مباشرًا وخطة فردية، لذا تظل الخيار المناسب للتقييم السريري والتأهيل. HEALTHMATE قد يقلل كلفة التذكير والمتابعة بين الجلسات، لكنه لا يحل محلها. تُملأ المقارنة المحلية بعد جمع عروض أسعار من مراكز مصرية: سعر الجلسة [المصدر]، متوسط عدد الجلسات [المصدر]، وسعر اشتراك البرنامج المقترح [المصدر].

## خطة التحقق

تجربة محدودة مع مستخدمين ومختصين، ومقارنة العدّ والوضعية بمراجعة بشرية بموافقتهم. لا تُنشر ادعاءات دقة قبل قياسها على أجهزة وأجسام وإضاءات متنوعة. مؤشرات القرار: إتمام الإعداد، نجاح بدء الكاميرا، ثبات التطبيق، فهم حدود المنتج، والاحتفاظ الأسبوعي.
